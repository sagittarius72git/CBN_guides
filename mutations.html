CBN 変異図鑑

Cataclysm: Bright Nights の変異と特性を、公式の日本語名と説明文でまとめたもの。BN main の JSON と公式翻訳から自動生成していて、効果の数値はゲーム内では確認していない。

変異の方法

変異が起きる主な手段

  • 変異原物質を飲む: 1回変異する（強いものは1/3で2回）。痛みが出て、空腹・渇き・疲労が増え、1/6で転倒する。飲む変異原では閾値は越えない。
  • カテゴリの変異原物質（ビースト変異原物質など）: そのカテゴリの変異から選ばれる。「汎用の変異原では出ない」変異も出る。
  • 汎用の変異原物質: ワールド設定の BALANCED_MUTATIONS（既定オン）では、飲むと変異原が体に蓄積し、その後しばらく、変異か変異の消失が少しずつ起きる。オフなら旧方式で、1/3で悪い変異になる。
  • 血清を注射する（変異原性血清、ビースト血清など）: 一度に複数回変異し、注射の前後で閾値を越える判定がある。本体で閾値を越える判定があるのは注射だけ（MODの呪文には判定付きのものもある）。
  • 放射線: ワールド設定「放射能による変異」（既定オン）のとき、15分ごとに、被曝量が100〜10000の乱数を上回ると変異し、被曝量が50減る。被曝量100を超えたあたりから起き、多いほど起きやすい。
  • そのほか: 汚水サンプルを飲む（1/4）、マーロス系の食べ物やマイカスに適応していない状態でのマイカスフルーツ、変異を起こすアーティファクト、モンスターの放射線ビーム（被曝したとき1/6）、変異「不安定な遺伝子」（平均48時間に1回）、「混沌の遺伝子」「遺伝子劣化」（平均12時間に1回）。
  • MOD: アルカナの帳の探索者は修復された儀式の剣の呪文「異界との契約」で、カタクリズム++のセンチネルはナノ変異原血清の注射で変異する。

変異の進み方

  • 前提の変異を持っていなければ、先に前提の方へ変異する。上位版（変化先）は、元の変異を置き換える形で得る。
  • 排他の変異を持っていると、まずそれが消え、その後で変異が起きる。
  • 上位版をすでに持っている変異を引くと、変異は増えず、上位版が1段階元に戻る。

閾値の越え方

  • カテゴリの変異を集めると、そのカテゴリの「強度」が上がる。持っている変異1つにつき、その変異のカテゴリに8、その前提（置き換わって今は持っていないものも含む）のカテゴリに4、さらにその前提に2…と加わる。上位の変異ほど強度への寄与が大きい。キャラ作成で選んだ特性は数えない。
  • そのカテゴリの血清を注射したときに、そのカテゴリが一番強度の高いカテゴリで、強度が50を超えていれば判定がある。成功率は「そのカテゴリの強度 ÷ 全カテゴリの強度の合計」（クマとアルファは +50 の上乗せ）。
  • 失敗すると、強度が60を超えていれば短い気絶、80・100を超えると痛みと気絶が加わる。
  • 一度どこかの閾値を越えると、別カテゴリの閾値は越えられない。閾値を越えると、そのカテゴリの閾値後の変異が出るようになる。

変異を消す

  • 変異治療薬（飲む）: 1つから最大4つの変異が消える。変異治療血清（注射）: 4つから最大8つ消えるが、痛み・空腹・渇き・疲労が増える。
  • 消えないもの: キャラ作成で選んだ特性、閾値を越えたカテゴリの閾値前の変異、治療できないと設定された変異。上位版は1段階ずつ元に戻る。

手に入れ方

  • 変異原物質・血清・治療薬は、研究所などで見つかるほか、料理スキルでレシピを覚えれば作れる。変異原物質は汚染された肉や血液、漂白剤、アンモニアなど、カテゴリの変異原物質は変異原物質にそのカテゴリの材料（ビーストなら動物の血液の濃縮液）を足し、血清は変異原物質2つから作る。

出典: BN main のソース（src/mutation.cpp、src/iuse_actor.cpp、src/iuse.cpp、src/suffer.cpp）と data/json/recipes/chem/mutagen.json。ゲーム内では確認していない。

見方
  • ポイントはキャラ作成時のコスト。プラスが有利な特性、マイナスが不利な特性。
  • 「×1.2」は倍率、「+2」は加算。移動コストのように小さいほど良い数値は、項目名にそう書いてある。
  • 体温補正の「気温+2.5℃相当」は、気温がそれだけ高いのと同じ効果という意味。「冷えているときは」の分は、体温が平熱を下回っているときだけ働き、平熱を超えると止まる。
  • 同じ種類の補正を持つ変異が複数あると、多くの数値は足し算にならず、一番強いものだけが効く。
  • 前提は「先にどれかを持っていないと得られない」、変化先は「変異が進むとこれに置き換わる」。
  • 閾値: カテゴリの変異を重ね、注射型の変異原で閾値を越えると、上位の変異が得られるようになる。別カテゴリの閾値は越えられない。
  • 汎用の変異原はカテゴリ指定のない変異原。「汎用の変異原では出ない」変異も、そのカテゴリの変異原なら出る。
  • 点線の下線がついた語（効果の項目名や「意欲」「士気」）にマウスを乗せるか、タップすると、ゲームで何に効くかが出る。
  • 上の MOD のボタンで、載せる MOD を選べる。MOD の変異には「MOD:」の印が付き、本体の変異を MOD が書き換える分は「〇〇導入時」の行に出る。各 MOD は単独で入れたときの内容で、MOD 同士を一緒に入れたときだけ働く追加ファイル（mod_interactions）は反映していない。
  • カテゴリの「概要」は、そのカテゴリの変異の効果をまとめた要約。体格はキャラの大きさ（とても小さい〜とても大きい）が変わる変異のこと。
  • 載せていないもの: 外見（肌・目・髪・ひげ）、デバッグ用、NPCの経歴や内部用の非表示特性、廃止済みの変異。
  • カテゴリ「魚（FISH）」は、公式訳データでは「魚を釣る」になっている。同じ英単語の別の訳が当たっているので、ここでは「魚」と書いている。
